## Usage

```tsx
import { ChartV2 } from '@juspay/blend-design-system'
import Highcharts from 'highcharts'

function MyComponent() {
    const options = {
        title: {
            text: 'Monthly Sales',
        },
        series: [
            {
                type: 'line',
                name: 'Sales',
                data: [1, 2, 3, 4, 5],
            },
        ],
    }

    return (
        <ChartV2
            highcharts={Highcharts}
            options={options}
            skeleton={{ show: false }}
            noData={{
                title: 'No Data Available',
                subtitle: 'Try adjusting your filters',
            }}
        />
    )
}
```

## ChartContainerV2

A wrapper component for chart layouts:

```tsx
import { ChartContainerV2, ChartHeaderV2 } from '@juspay/blend-design-system'
;<ChartContainerV2>
    <ChartHeaderV2>
        <h3>Sales Overview</h3>
    </ChartHeaderV2>
    <ChartV2 options={options} />
</ChartContainerV2>
```

## ChartV2Legend

Custom legend component for chart interactivity:

```tsx
import { ChartV2Legend } from '@juspay/blend-design-system'
;<ChartV2Legend
    chartRef={chartRef}
    customLegendItems={[
        { key: 'sales', name: 'Sales', color: '#00A6FF', value: 1200 },
        { key: 'visits', name: 'Visits', color: '#10B981', value: 3400 },
    ]}
    layout="horizontal"
/>
```

## ChartV2Fullscreen

Wrapper component for fullscreen chart functionality:

```tsx
import { ChartV2Fullscreen, ChartV2 } from '@juspay/blend-design-system'
;<ChartV2Fullscreen>
    <ChartV2 options={options} />
</ChartV2Fullscreen>
```

## ChartV2Skeleton

Standalone skeleton loader for chart loading states:

```tsx
import { ChartV2Skeleton } from '@juspay/blend-design-system'
;<ChartV2Skeleton show={true} variant="rectangular" height={300} />
```

## Localization

ChartsV2 has 4 built-in strings: 2 shown on screen and 2 read only by screen readers. Everything else it renders comes from your props and data.

| Key                            | English default                        | Where it appears |
| ------------------------------ | -------------------------------------- | ---------------- |
| `chart.a11y.container`         | `Chart container`                      | Screen reader    |
| `chart.a11y.legend`            | `Chart legend`                         | Screen reader    |
| `chart.empty.no-data`          | `No data available`                    | On screen        |
| `chart.empty.no-data-subtitle` | `Data will appear here once available` | On screen        |

All keys are also listed in the [message catalog](/docs/internationalization/message-catalog#chart), under [`chart.*`](/docs/internationalization/message-catalog#chart).

`chart.*` is shared with Charts, so translating it once covers both.

### Translating

Pass a `locale` and a `t` function to `ThemeProvider`. Any key you don't translate falls back to its English default.

```tsx
import { ThemeProvider, createTranslator } from '@juspay/blend-design-system'

const t = createTranslator({
    'chart.empty.no-data': 'Aucune donnée disponible',
    'chart.a11y.container': 'Conteneur de graphique',
})

export function Root() {
    return (
        <ThemeProvider locale="fr-FR" t={t}>
            <App />
        </ThemeProvider>
    )
}
```

Using i18next, FormatJS or another library? Pass its translate function as `t` instead; see [Internationalization](/docs/internationalization/overview).

### Notes

- Numbers and dates follow the provider `locale`. Series and category names are your data.

## Component Tokens

You can style the ChartsV2 component using the following tokens:

```tsx
export type ChartV2TokensType = {
    container: {
        background: CSSObject['background']
        borderRadius: CSSObject['borderRadius']
        border: CSSObject['border']
        padding: CSSObject['padding']
    }
    skeleton: {
        height: CSSObject['height']
        borderRadius: CSSObject['borderRadius']
    }
    noData: {
        container: {
            padding: CSSObject['padding']
            textAlign: CSSObject['textAlign']
        }
        title: {
            fontSize: CSSObject['fontSize']
            fontWeight: CSSObject['fontWeight']
            color: CSSObject['color']
        }
        subtitle: {
            fontSize: CSSObject['fontSize']
            color: CSSObject['color']
        }
    }
    header: {
        padding: CSSObject['padding']
        borderBottom: CSSObject['borderBottom']
    }
}
```
