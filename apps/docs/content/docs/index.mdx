## Build with confidence

Blend gives product teams a shared language for design and development. Use these docs to learn the foundations, components, and patterns that make up the system.

## What's inside

- **Foundations** for color, typography, spacing, and layout.
- **Components** with clear usage guidance and accessibility notes.
- **Patterns** for putting the pieces together in real product flows.

Start with the getting-started guide, then explore the component documentation as you build.
