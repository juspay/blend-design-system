## Usage

```tsx
import {
    SplitTag,
    TagColor,
    TagSize,
    TagShape,
    TagVariant,
} from '@juspay/blend-design-system'

function MyComponent() {
    return (
        <SplitTag
            primaryTag={{
                text: 'Status',
                variant: TagVariant.NO_FILL,
                color: TagColor.PRIMARY,
            }}
            secondaryTag={{
                text: 'Active',
                variant: TagVariant.ATTENTIVE,
                color: TagColor.SUCCESS,
            }}
            size={TagSize.MD}
            shape={TagShape.ROUNDED}
        />
    )
}
```

## Localization

SplitTag has 2 built-in strings: 2 read only by screen readers. Everything else it renders comes from your props and data.

| Key                      | English default          | Where it appears |
| ------------------------ | ------------------------ | ---------------- |
| `tag.a11y.split`         | `{primary}: {secondary}` | Screen reader    |
| `tag.a11y.split-unnamed` | `Split tag`              | Screen reader    |

All keys are also listed in the [message catalog](/docs/internationalization/message-catalog#tag), under [`tag.*`](/docs/internationalization/message-catalog#tag).

`tag.*` is shared with TagV2, so translating it once covers both.

### Translating

Pass a `locale` and a `t` function to `ThemeProvider`. Any key you don't translate falls back to its English default.

```tsx
import { ThemeProvider, createTranslator } from '@juspay/blend-design-system'

const t = createTranslator({
    'tag.a11y.split': '{primary} : {secondary}',
    'tag.a11y.split-unnamed': 'Étiquette double',
})

export function Root() {
    return (
        <ThemeProvider locale="fr-FR" t={t}>
            <App />
        </ThemeProvider>
    )
}
```

Using i18next, FormatJS or another library? Pass its translate function as `t` instead; see [Internationalization](/docs/internationalization/overview).

## Component Tokens

You can style the SplitTag component using the following tokens:

```tsx
export type SplitTagTokenType = {
    gap: CSSObject['gap']
    borderRadius: {
        [key in TagSize]: {
            [key in TagShape]: CSSObject['borderRadius']
        }
    }
    padding: {
        [key in TagSize]: CSSObject['padding']
    }
    backgroundColor: {
        [key in TagVariant]: {
            [key in TagColor]: CSSObject['backgroundColor']
        }
    }
    border: {
        [key in TagVariant]: {
            [key in TagColor]: CSSObject['border']
        }
    }
    text: {
        color: {
            [key in TagVariant]: {
                [key in TagColor]: CSSObject['color']
            }
        }
        fontSize: {
            [key in TagSize]: CSSObject['fontSize']
        }
        fontWeight: {
            [key in TagSize]: CSSObject['fontWeight']
        }
    }
}
```
